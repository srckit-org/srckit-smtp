# srckit-smtp

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Configure and test SMTP connections.

## Features

- **Tester** — Configure SMTP host, port, credentials, and see connection string
- **Config** — Reference of common SMTP providers (Gmail, SendGrid, Mailgun, AWS SES, Mailtrap)

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
